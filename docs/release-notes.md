# Release 1.0.0

- 三个可改名的日常栏目、今日复盘和明日任务。
- 五套主题，Markdown 实时预览，设置模板预览。
- 金句文档自定义路径，公开默认名句与出处。
- 一个近期目标，按天倒计时，04:00 换日。
- 本地 Markdown 日记同步，按年月识别目录、固定区域更新与冲突保护。
- Windows 便携版、浅色多尺寸图标、定时提醒。

附带文件：`日有所积-Windows便携版.zip` 与同名 `.sha256`。

完整解压后双击 `日有所积.exe`。默认记录在 `data/`，不要将自己的 data 文件夹重新打包分享。升级前请备份，详见 docs/maintenance.md。
