# 更新与维护

## 更新

1. 确认各窗口的记录已保存，关闭旧窗口。
2. 备份原软件的整个 `data/` 文件夹。
3. 将新便携包解压到新目录，复制原 `data/` 到新目录。
4. 若笔记和金句原来放在旧软件目录内，将对应路径在设置中改到新目录；外部笔记路径可保留。
5. 在旧目录停止服务（见下方），然后启动新目录的 `日有所积.exe`。

也可在备份后用新程序文件覆盖旧目录，保留 `data/`，运行 `更新并打开.cmd`。不要同时启动两个正式目录来编辑同一套数据。

## 备份

- 主记录：`data/state.json`。
- 日常备份：`data/backups/`；日记写入前备份：`data/diary-backups/`。
- 浏览器草稿：`data/browser-light` 或 `data/browser-dark`；不要在尚未保存时删除。
- 设置 → 记录与同步 → 导出全部记录，可导出 JSON。
- 外部笔记和外部金句文档需要另外备份。

## 提醒或启动失败

确认已完整解压，目录可写，并安装 Chrome 或 Edge。检查 `data/setup-warning.log` 和 `data/server-error.log`。系统禁止注册计划任务时，手动启动仍可用。

提醒不会唤醒休眠中的电脑，也不补弹错过的时间。计划任务名称是 `Lunaria-Growth-Board-Startup` 与 `Lunaria-Growth-Board-Reminder`，每个 Windows 用户只应保留一份正式安装。

## 停止与移除

先完成保存并关闭窗口，再在任务管理器核对命令行，结束运行本目录 `server.py` 的 Python 进程。不要结束其他 Python 程序。

卸载时在 Windows 任务计划程序中删除上述两个任务。确认笔记与记录已备份后，再删除软件文件夹；程序不会自动删除外部笔记。

## 端口

默认 47831，不可用时自动尝试备用端口。实际地址在 `data/runtime.json` 中，通过启动器打开即可。
