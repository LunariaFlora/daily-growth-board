# 笔记与金句

## 日记目录

选择日记根目录后，程序按目标日期寻找对应年份、月份和当天日记。

| 类型 | 支持的示例 |
| --- | --- |
| 月份目录 | `26.10复盘`、`2026-10`、`2026年10月` |
| 日期文件 | `10.26.md`、`2026-10-26.md` |
| 带标题的日期 | `10.26 今日复盘.md`、`2026-10-26 随笔.md` |

`25.10复盘` 与 `26.10复盘` 分别属于 2025、2026 年，不会混用。支持直接放日期文件的平铺目录；平铺目录跨年份建议使用完整的 `YYYY-MM-DD.md` 文件名。

缺少当月目录时，沿用已有月份命名；缺少当天日记时，沿用最近日记的日期格式。空根目录默认使用 `YY.M复盘/M.D.md`。直接选月目录只能写该月；需要跨月请选根目录。也可指定一篇 `.md` 文件，按日期分别存放看板区域。

同月重复目录、同日重复笔记或不支持的分类会报错，不会猜测。路径下方会预览将写入的文件。更改路径不会搬动旧笔记。

## 同步保护

首次同步在日记末尾建立带隐藏标记的区域；以后只替换该区域，区域外字节保持不变。请把手写内容放在区域外。手动改动区域内部或删除标记后，同步会暂停并提示冲突。

三个栏目都为空时不会新建记录。已同步过的记录被清空时，会更新既有区域。日记修改前备份在 `data/diary-backups/`；不要在未备份的情况下手动删除同步标记。

## 金句文档

默认 `data/个人金句.md`；设置中的金句路径接受完整 `.md` 文件路径。留空恢复默认位置。父目录须存在；新文件创建公开示例，已有文件不覆盖。UTF-8 编码，格式如下：

```markdown
## 一句提醒

> 千里之行，始于足下。

来源：老子《道德经》第六十四章
```

来源可省略，多行引用每行加 `>`。每天选一句，同一天保持稳定，有多个候选时避免连续两天相同。修改文档后重新打开或刷新看板可读取更新。金句的“原话出处”是引用来源，不是当天日记的同步位置。
